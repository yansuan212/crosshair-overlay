# 屏幕准星 · 方案 D（纯 C + Win32）

> **未注入游戏、未 hook、未读写游戏内存。** 只是一个显示在屏幕最上层的透明窗口。
> 样式：**屏幕正中央一个红色圆点**。交付物：单个 `crosshair.exe`，约 55 KB，零依赖，双击即用。

---

## 二、快速开始

1. 双击 `crosshair.exe`
2. 屏幕正中央出现一个红色圆点
3. 托盘区（右下角）出现一个红色准星图标，**右键**它是菜单

首次运行会在 exe 同目录生成 `crosshair.ini`，可以随意修改。

> 💡 如果某个热键按了没反应，**先看 `crosshair.ini.log`** ——
> 程序会把三个热键的注册结果都写进去，哪条显示"注册失败"就是被别的软件占用了。
> 这时用 `tools/hotkey_probe.exe` 换个空闲的键。

> 💡 想不打开程序就验证"红点画得对不对"，跑 `crosshair.exe --selftest`，
> 它会导出一张 PNG 和一份文字报告（见第五节）。

## 三、热键

全部为 **Ctrl + Alt + 组合键**（与方案 A 保持一致）：

| 热键 | 功能 |
|---|---|
| `Ctrl + Alt + H` | 显示 / 隐藏准星（游戏中随时切换） |
| `Ctrl + Alt + ↑` | 变大（直径 +2 px） |
| `Ctrl + Alt + ↓` | 变小（直径 −2 px） |
| `Ctrl + Alt + C` | 换个颜色（红→亮红→深红→品红→绿→青→黄→白 循环） |
| `Ctrl + Alt + I` | 重新加载 `crosshair.ini`（**改完配置按一下，不用重启**） |
| `Ctrl + Alt + Q` | 退出程序 |

> 💡 用 `↑` / `↓` / `C` 调出来的大小和颜色会**立即写回 `crosshair.ini`**，重启后仍然保持。

> ⚠️ **为什么重载键是 I 而不是 R**：本机 `Ctrl+Alt+R` 被 **NVIDIA 游戏内覆盖**占用
> （录制快捷键），注册会静默失败。实测已被占用的组合：
> `Ctrl+Alt+{ F, L, M, O, R, X, Z }`。
> 换热键前请先运行 `tools/hotkey_probe.exe` 探测哪些键空闲，别凭感觉挑。

托盘图标：双击 = 显示/隐藏，右键 = 菜单（含变大/变小/换色/重载）。

## 四、配置项（`crosshair.ini`）

**当前样式：屏幕正中央一个红色圆点。**

```ini
[crosshair]
size=8           ; 红点直径（像素）。想大就调大，建议 3 - 30
colorR=255       ; 颜色 - 红 (0-255)
colorG=0         ; 颜色 - 绿 (0-255)
colorB=0         ; 颜色 - 蓝 (0-255)
opacity=230      ; 整体不透明度 0-255，255 = 完全不透明
outline=0        ; 是否给红点加黑色描边 0/1
monitor=0        ; 显示器序号：0 = 主显示器

; 以下为旧「十字准星」样式的遗留参数，圆点模式下不使用，保留仅为兼容：
thickness=2
gap=0
centerDot=0
dotSize=3
```

**常用改法举例**

| 想要的效果 | 怎么改 |
|---|---|
| 红点变大 | `size=16` |
| 红点变小 | `size=5` |
| 更实（不透明） | `opacity=255` |
| 稍微淡一点 | `opacity=180` |
| 亮背景更清晰 | `outline=1`（加黑边） |
| 换深红 | `colorR=180` |

> ⚠️ `size` 别填 0 —— 会被钳到最小值，红点小到看不见。

改完保存 → 按 `Ctrl+Alt+I` 立即生效。

也可以不改文件，直接用热键调：`Ctrl+Alt+↑ / ↓` 调大小、`Ctrl+Alt+C` 换色，
调完会自动写回本文件（注释和其他配置项原样保留）。

## 五、自己重新编译

本机已装 MinGW-w64 GCC 8.1（`D:\mingw64`），**不需要安装任何东西**：

```bat
:: 双击 build.bat，或者命令行：
"D:\mingw64\bin\g++.exe" -O2 -s -municode -mwindows -o crosshair.exe ^
    src\crosshair.cpp -lgdi32 -luser32 -lshell32 -lole32
```

编译耗时约 2 秒，产物约 52 KB，只依赖 `GDI32 / KERNEL32 / msvcrt / SHELL32 / USER32`
—— 全是 Windows 自带的，**拷到任何 Win7+ 电脑上都能直接跑**。

### 自检模式（不用眼睛看也能验证画对了）

```bat
crosshair.exe --selftest
```

不创建任何窗口、不抢焦点，纯内存渲染后导出：

- `crosshair.ini.selftest.png` —— 中心 320×320 的实际渲染图
- `crosshair.ini.selftest.txt` —— 文字报告（包围盒尺寸、红色像素数、抗锯齿像素数）

报告示例（直径 8）：

```
图形包围盒: x[156..163] y[156..163]  宽=8 高=8
  [OK] 确实画出了红色像素 (60 个)
  [OK] 包围盒 8x8 与设定直径 8 相符
  [OK] 宽高相等 (8=8) = 圆形，不是方形
  [OK] 有 60 个半透明边缘像素 = 抗锯齿生效
```

### 附：热键探测工具

`tools/hotkey_probe.exe`（也用同样的 g++ 编译）会逐个尝试注册
`Ctrl+Alt+A~Z / 0~9 / F1~F12`，把被占用的列出来：

```bat
"D:\mingw64\bin\g++.exe" -O2 -s -municode -o tools\hotkey_probe.exe tools\hotkey_probe.c -luser32
```

## 六、技术实现要点（为什么这么轻）

对标 GitHub 上的 `zkxs/simple-crosshair-overlay`（Rust）和 `mesrefoglu/Crosshair`（C#，164 KB）：

1. **窗口三件套**：`WS_EX_LAYERED`（分层）+ `WS_EX_TRANSPARENT`（鼠标穿透，点击直接到游戏）+ `WS_EX_TOPMOST`（置顶）。
2. **透明用每像素 alpha**：维护一张 32 位 ARGB 位图，`memset` 清零 = 全透明，
   只在中心填出一个圆。
   通过 `UpdateLayeredWindow` 一次性提交。
   > 这里避开了常见的 `LWA_COLORKEY` 方案 —— 那个和 `LWA_ALPHA` 互斥，
   > 且分层窗口下直接 `BitBlt` 不生效，是很多人踩的坑。
3. **圆点带抗锯齿**：逐像素算到圆心的距离，边缘像素按覆盖率做 alpha 混合，
   所以圆边是平滑的，不是锯齿状。
4. **性能秘诀 = 不重绘**：**没有定时器、没有循环**。只在启动、改配置、分辨率变化时画一次。
   平时窗口静止 → **CPU 占用 0%**，内存约 2–3 MB。
5. **DPI 感知**：动态调用 `SetProcessDPIAware()`，配合 `GetSystemMetrics` 取物理像素，
   4K / 缩放环境下红点仍在正中心。
6. **单实例互斥锁**：防止重复启动堆叠多个准星。
7. **落盘日志**：WinExe 没有控制台，热键注册结果与配置值都写进 `crosshair.ini.log`。

## 七、已知限制与注意

- ⚠️ **独占全屏（Exclusive Fullscreen）下准星不可见**，请把游戏设为
  **无边框窗口 / 窗口模式**。这是 Windows 架构限制，所有同类工具一样。
- ⚠️ **反作弊**：本程序不注入、不 hook，对 VAC / EAC 这类反作弊是安全的，
  但**内核级反作弊**可能拦截顶层窗口。竞技游戏使用前请自行确认游戏政策。
- ⚠️ 当前窗口只覆盖主显示器（`monitor=0`）。副屏需求的代码路径已写好但未充分验证，
  如需多屏支持请告知，我再补完并测试。
- HDR 开启时颜色可能略有偏差（Windows 对分层窗口的 HDR 合成限制）。
