# 屏幕准星 Crosshair Overlay

Windows 桌面正中央的**红色圆点**，覆盖在游戏画面之上，用于 FPS 瞄准参考。

> **只提供视觉显示。不注入游戏、不修改游戏文件、不读写游戏内存。**

---

## 一、编译

双击本文件夹下的 **`build.bat`** 即可。它会调用本机的 .NET SDK 编译，产物在 `dist\Crosshair.exe`。

也可以手动执行（在本文件夹下）：

```bat
cd src
"C:\Program Files\dotnet\dotnet.exe" build Crosshair.csproj -c Release -o ..\dist
```

编译产物约 **21 KB**（依赖系统自带的 .NET Framework 4.8 运行时，无需安装任何东西）。

---

## 二、运行

双击 `dist\Crosshair.exe`。屏幕正中央立刻出现红色圆点。

- 首次运行会在 exe 同目录自动生成 `config.txt`
- 程序常驻系统托盘（右下角），图标是默认应用程序图标

---

## 三、热键

全部为 **Ctrl + Alt + 组合键**：

| 热键 | 作用 |
|---|---|
| `Ctrl+Alt+H` | 隐藏 / 显示红点 |
| `Ctrl+Alt+↑` | 变大（直径 +2px） |
| `Ctrl+Alt+↓` | 变小（直径 −2px） |
| `Ctrl+Alt+C` | 循环切换颜色（红→亮红→深红→品红→绿→青→黄→白） |
| `Ctrl+Alt+Q` | 退出程序 |

托盘图标右键也有同样的菜单项。

---

## 四、配置文件 config.txt

改完保存即可，**下次启动生效**（热键调整会自动写回该文件）。

```ini
diameter=8       # 圆点直径（像素），2~200
color=255,0,0    # 圆点颜色 RGB，255,0,0 为纯红
```

> 兼容旧配置：老版本里的 `size=`（准星臂长）会被当作直径读取，其余旧字段忽略。

## 五、自测（无人值守验证渲染，不弹窗）

```bat
dist\Crosshair.exe --selftest
```

不创建窗口，只在内存里渲染一次红点并输出：

- `dist\selftest.png` —— 中心区域 320×320 的渲染图（黑底）
- `dist\selftest.txt` —— 屏幕分辨率、圆心坐标、直径、颜色、渲染出的红色像素数

用途：确认红点居中、参数生效，且整个过程不打扰当前桌面。

## 六、原理与性能

一个**原生 Win32 窗口**（不用 WinForms 控件树），关键点：

1. 扩展样式四件套：
   `WS_EX_LAYERED`（分层透明）+ `WS_EX_TRANSPARENT`（鼠标穿透）+
   `WS_EX_TOPMOST`（置顶）+ `WS_EX_TOOLWINDOW`（不出现在 Alt+Tab）
2. `SetLayeredWindowAttributes(..., LWA_COLORKEY)` 把背景键色 `RGB(1,2,3)` 声明为透明
3. **不开定时器、不做循环重绘** —— 只在启动和参数变化时各画一次，之后窗口静止
4. 绘制走**内存 DC 双缓冲**（画完一次性 `BitBlt` 贴出），无闪烁
5. manifest 声明 `PerMonitorV2` DPI 感知 + `SetProcessDPIAware()`，
   用 `GetSystemMetrics(SM_CXSCREEN)` 取物理像素，保证任何缩放/4K 下都真居中

因此运行时 CPU 占用接近 0，内存约 47 MB（.NET Framework 承载进程的基线开销）。

## 七、已知限制

- ⚠️ **独占全屏（Exclusive Fullscreen）下红点不可见** —— 这是 Windows 架构限制，不是 bug。
  请让游戏使用**无边框窗口 / 窗口模式**。
- ⚠️ 部分游戏开了 HDR 或走特殊渲染路径时，overlay 表现可能异常。
- ⚠️ **反作弊提示**：本程序不注入、不 hook，对 VAC / EAC 这类常规反作弊是安全的；
  但**内核级反作弊**可能检测外部 overlay 窗口，存在封号风险，请自行确认所玩游戏的策略。

## 八、目录结构

本方案完整收在自己的文件夹里，与方案 D 并列：

```
准星/                                  # 工作空间根目录
├── 需求方案.md                        # 项目总需求与选型调研（两条路线共用）
├── 方案A-CSharp-Win32/                # ← 本方案（C#）
│   ├── 使用说明.md                    # 本文件
│   ├── build.bat                      # 一键编译
│   ├── src/
│   │   ├── Crosshair.cs               # 主程序（单文件）
│   │   ├── Crosshair.csproj           # 工程文件
│   │   └── app.manifest               # DPI 感知 / 权限声明
│   └── dist/
│       ├── Crosshair.exe              # 编译产物（约 21 KB）
│       ├── Crosshair.exe.config
│       └── config.txt                 # 首次运行自动生成
└── 方案D-C-Win32/                     # 另一条路线（纯 C + Win32）
```

> 下面各节的路径均**相对于本文件夹**。
